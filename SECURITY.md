# Security Policy

## Supported version

Only the current default branch is reviewed for security fixes.

## Private reporting

Do not open a public issue containing credentials, tokens, authorization codes, cookies, personal data, or exploit details.

Report a vulnerability privately by emailing `hi@hanbintan.com` with:

- the affected commit
- the impacted route or function
- reproduction steps using fake data
- expected and observed behavior
- suggested containment, if known

Do not test against systems or accounts you do not own or have permission to assess.
Please allow reasonable time for triage before publishing details.

## Scope

Useful reports include authentication bypass, account-linking confusion, session fixation, callback replay, CSRF, open redirects, credential exposure, injection, and authorization failures.

The repository is a reference implementation and has no supported public production service.
